# Rock-Paper-Scissors-C
A simple Rock Paper Scissors game developed in C.
This project allows a user to play the classic Rock Paper Scissors game against the computer. The computer generates a random choice, and the program determines the winner based on the game rules.

##  Features
- User vs Computer gameplay
- Random computer choice
- Win/Lose/Draw detection
- Beginner-friendly C project
- Console-based interface
## 🛠 Technologies Used
- C Programming
- GCC Compiler
- ##  How to Run
Compile the program:

```bash
gcc rock_paper_scissors.c -o game
```
Run the program:

```bash
./game
```

For Windows:

```bash
game.exe
```
##  Game Rules

- 🪨 Rock beats Scissors
- ✂️ Scissors beat Paper
- 📄 Paper beats Rock

##  Sample Output

```text
------ Rock Paper Scissors Game ------

1. Rock
2. Paper
3. Scissors

Enter your choice (1-3): 1
Your Choice: Rock
Computer Choice: Scissors

Result: Congratulations! You Win.
```
